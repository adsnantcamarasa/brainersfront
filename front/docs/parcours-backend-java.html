Parcours · devenir dev back-end en reconstruisant la chaîne à la main

Back-end brique par brique

Entre le clic d'un client et ta base de données, une requête traverse une vingtaine de briques. Spring Boot les cache derrière quelques annotations. Ce parcours te les fait reconstruire en Java, avec le JDK et presque rien d'autre, en recodant l'API Greenlight du livre Let's Go Further. À la fin, aucune annotation Spring ne sera magique : tu sauras ce qu'elle fait, parce que tu l'auras écrite.

3 · L'ordre

Le parcours, en dix phases

Le fil rouge est Greenlight, l'API de films de Let's Go Further. Le livre construit l'API en Go avec la bibliothèque standard, le routeur httprouter et quelques petits paquets. Toi, tu lis chaque chapitre pour comprendre quoi faire et pourquoi, puis tu le recodes en Java en construisant d'abord la brique dont il a besoin. À la fin, ton API expose les mêmes routes que celle du livre :

Les règles du jeu

  • Autorisé : le JDK 25, le driver JDBC de PostgreSQL et JUnit.
  • Outils autour de ton code : PostgreSQL, curl, psql, Docker, Caddy, Mailpit et un outil de charge.
  • Interdit jusqu'à la phase 10 : Spring, Tomcat, Jetty, Jackson, Gson, Hibernate, HikariCP, Flyway, Lombok.
  • Jamais recodé : la cryptographie. Le JDK fournit PBKDF2, SHA-256 et SecureRandom.
  • Commence sans Maven (java Main.java lance un programme de plusieurs fichiers depuis Java 22). Passe à Maven quand le projet grossit : c'est un outil, pas une bibliothèque.

La méthode, pour chaque brique

  1. Comprendre : la vidéo Sriniously de la brique, ou le chapitre du livre.
  2. Spécifier : ce que la brique doit faire, la RFC si elle existe.
  3. Coder le minimum qui fait passer Greenlight à l'étape suivante.
  4. Tester avec JUnit et curl.
  5. Comparer : lire le code de la vraie brique (Tomcat, Jackson, HikariCP, Spring) une fois la tienne écrite. C'est là que tu apprends le plus.

Les durées

Ce sont des ordres de grandeur, à environ 8 heures par semaine : huit à neuf mois au total. Elles varient beaucoup d'une personne à l'autre. Ne saute pas une phase pour aller plus vite : chaque phase utilise les briques des précédentes.

Pour chaque ressource que tu m'as donnée, j'ai regardé ce qu'elle contient vraiment, si elle fait coder, et où elle a sa place dans le parcours. Vérifié le 22 octobre 2026.

Let's Go Further
Alex Edwards		 Version 1.27.1 pour Go 1.27, mise à jour le 3 octobre 2026. 22 chapitres, 614 pages, 59,95 $. Construit Greenlight, une API JSON de films sur PostgreSQL, avec la bibliothèque standard, httprouter et quelques petits paquets. Les chapitres 1 à 3 sont lisibles gratuitement en ligne. Fil rouge Le meilleur fil rouge possible : il couvre presque toutes les briques, dans un ordre qui marche. Lis un chapitre pour le quoi et le pourquoi, puis recode-le en Java. Le Go se lit facilement quand on connaît Java.
How Tomcat Works
Budi Kurniawan, Paul Deck		 Paru en 2004, sur Tomcat 4 et 5. Construit un conteneur de servlets pas à pas, en Java : un serveur web simple, un conteneur simple, le connecteur, puis les composants de Tomcat (lifecycle, loader, sessions, sécurité…). En partie Les chapitres 1 à 5 sont exactement la brique B03. Le reste, en survol, pour le vocabulaire. Le Java est d'avant les génériques et NIO : pour les noms actuels, la doc Architecture de Tomcat 11. Le livre neuf est difficile à trouver.
Crafting Interpreters
Robert Nystrom		 Gratuit en ligne. Construit un langage de programmation complet ; sa première moitié est en Java. En partie Pertinent pour ton parser JSON, mais seulement les ch. 4 (analyse lexicale), 5 (représenter le code) et 6 (analyse syntaxique). Le reste construit un interpréteur : passionnant, mais hors de ce parcours.
API Security in Action
Neil Madden, Manning		 Paru en novembre 2020. Exemples en Java 11+, sur le micro-framework Spark (Jetty). 13 chapitres : développement sûr, sécurisation de l'API Natter, cookies de session, jetons, JWT, OAuth 2, contrôle d'accès, puis microservices et IoT. À garder La meilleure ressource pratique sur la sécurité d'une API en Java. Fais les ch. 3 à 8 pendant la phase 8. Les ch. 9 à 13 (Macaroons, Kubernetes, IoT) sont facultatifs.
summer-framework
Michael Liao		 « A minimal Spring framework » en Java 21, licence GPL-3.0. Modules : conteneur IoC, AOP, JdbcTemplate et transactions, web (Servlet 6.0), boot. Le dossier step-by-step contient 11 étapes. Le tutoriel associé est en chinois. Le framework s'appuie sur Tomcat, Jackson, HikariCP et ByteBuddy. À garder Le bon plan pour B07, B11, B12 et le JdbcTemplate. Suis l'ordre des 11 étapes, lis le code, puis écris le tien. Le tutoriel se lit avec la traduction du navigateur. Comme il délègue le serveur, le JSON et le pool à des bibliothèques, toi tu brancheras tes propres briques à la place.
Backend from first principles
Sriniously, YouTube		 31 vidéos, 34,9 heures au total, de 4 minutes à 2 h 50. Indépendant du langage : HTTP, routage, sérialisation, authentification, validation, couches, design REST, PostgreSQL, cache, files de tâches, recherche, erreurs, configuration, logs, arrêt propre, sécurité, montée en charge, concurrence, tests, Twelve-Factor, OpenAPI, webhooks, DevOps. Carte Excellente carte des concepts, mais elle ne fait pas coder. Ne la regarde pas d'une traite : regarde la vidéo d'une brique juste avant de la coder. Les numéros sont indiqués dans le tableau et les phases.
boot.dev, parcours Back-end
Python et Go		 17 cours et 8 projets, environ 12 mois. Abonnement payant ; les premiers chapitres de chaque cours sont en démo gratuite. Ordre : Linux, Git, programmation objet et fonctionnelle, structures de données, gestion mémoire, Go, clients HTTP, SQL, serveurs HTTP, CDN, Docker, sécurité web, pub/sub. Inspiration Bonne liste de contrôle pour ne rien oublier, surtout pour le socle (phase 0). Ce n'est pas du Java : ne le suis pas en parallèle.
Threads et concurrence Pas une ressource, un sujet. Trois choix vérifiés : Java Concurrency in Practice (2006, la référence), OSTEP (gratuit, côté système), Modern Concurrency in Java d'A N M Bazlur Rahman (O'Reilly, septembre 2025 : threads virtuels, structured concurrency, scoped values). À garder JCIP ch. 1 à 8 pendant la phase 1, puis Modern Concurrency in Java pour les threads virtuels. Les Scoped Values sont finales depuis Java 25 ; la structured concurrency y est encore en preview.

Ce que j'ai ajouté, et pourquoi

Pour coder

  • CodeCrafters : le serveur HTTP en Java, avec des tests automatiques à chaque étape. Payant, mais les énoncés sont lisibles gratuitement : tu peux suivre les étapes sans abonnement.
  • JSONTestSuite : des centaines de cas limites pour savoir si ton parser JSON tient vraiment.
  • build-your-own.org : des livres courts qui font tout reconstruire (base de données, Redis, serveur web), dans d'autres langages que Java.

Pour comprendre en profondeur

  • Designing Data-Intensive Applications, 2e édition (2026) : la référence sur les transactions et les données. À lire par chapitres ciblés.
  • Use The Index, Luke! : les index et la pagination, gratuit et écrit pour les développeurs.
  • Le wiki HikariCP : pourquoi un petit pool est plus rapide qu'un gros.

Pour les bons réflexes

  • OWASP Cheat Sheets : comment stocker un mot de passe, gérer une session.
  • The Twelve-Factor App : douze règles pour une appli qui se déploie bien, en français.
  • Zalando RESTful API Guidelines : un guide de design d'API utilisé en production.
